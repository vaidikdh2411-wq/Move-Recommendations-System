# Movie Recommendation System

A simple Python project that recommends movies based on a movie you like.

## Features
- Recommends similar movies (content-based)
- Search movies by title

## How to Run
1. Clone the repo:
   `git clone https://github.com/vaidikdh2411-wq/Move-Recommendations-System.git`
2. Go to the folder:
   `cd Move-Recommendations-System`
3. Install the libraries:
   `pip install pandas numpy scikit-learn`
4. Run the program:
   `python main.py`

## Files
- `main.py` - main program
- `main_unit1_unit2.py` - Unit 1 and Unit 2 work
- `Dataset/` - movie data
- `output/` - results
